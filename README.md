Forragem - Simulação e Gestão 🌱

Projeto desenvolvido para simulação e gestão de produção de forragem, permitindo registrar, analisar e acompanhar dados de simulação com base em condições de solo, clima e histórico.

🚀 Tecnologias Utilizadas

Node.js – Ambiente de execução JavaScript no backend
TypeScript – Superset do JavaScript com tipagem estática
Prisma ORM – Gerenciamento de banco de dados e migrations
MySQL – Persistência de dados

⚙️ Como Rodar o Projeto
# Instalar dependências
npm install

# Rodar em modo desenvolvimento
npm run dev
